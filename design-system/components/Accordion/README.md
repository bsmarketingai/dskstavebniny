# Accordion

Nativní `<details>/<summary>`, funguje bez skriptu i s klávesnicí. Světlý `dsk-acc` — skladovost po prodejnách v detailu, šuplík filtru. Tmavý `--dark` — patička pod 820 px (Kamenné prodejny, Nákup, Služby…): 20/26 bíle, otevřená položka má oddělovač až pod obsahem. Šipka se otočí o 180°, s `prefers-reduced-motion` bez animace. Časté dotazy mají vlastní kartu FAQ.
