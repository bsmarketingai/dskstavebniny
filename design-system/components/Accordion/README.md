# Accordion

Nativní `<details>/<summary>` — funguje bez skriptu i s klávesnicí. Světlá varianta pro detail (skladovost po pobočkách), šuplík filtru a parametry; tmavá `--dark` pro patičku pod 820 px (Kamenné prodejny, Nákup, Služby, O nás…). Šipka se otočí o 180°, s `prefers-reduced-motion` bez animace. Mobilní menu kategorií používá stejný princip se čtverečkem plus/mínus pro 1. úroveň.
