# PriceStock

Cena s DPH je vždy hlavní (`primary-700`, v kartě 22 px, v detailu `--lg` 40 px), pod ní cena bez DPH (`secondary-600`). Přeškrtnutá původní cena a sleva jsou červené — červená je vyhrazená slevám, proto cena sama červená není. Skladovost `dsk-stock` zeleně s počtem kusů; mimo sklad `--out` šedě s termínem.
