# FormCard

Karta formuláře (košík krok 2, kontrola v kroku 3, poptávka): rámeček `secondary-200`, `radius-lg`. Hlavička na `secondary-100` s ikonou ve čtverci a nadpisem 24/30, vpravo volitelně jemné tlačítko („Máte účet? Přihlaste se“). Tělo: mřížka 2 sloupce (mezera 20 × 24), pod 820 px jeden. Rozbalovací části („Nákup na firmu“, „Vytvořit nový účet“) jako další karta se zaškrtávátkem v hlavičce.
