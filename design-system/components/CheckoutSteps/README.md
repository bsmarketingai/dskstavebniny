# CheckoutSteps

Ukazatel 3 kroků objednávky nad obsahem košíku (BSSHOP `OrderNavigator`). Aktivní krok je širší (flex 2,2), podklad `primary-50`, rámeček `primary-300`, číslo v tmavém poli `primary-700` přilepeném k levému okraji (rádius 5 0 0 5, navazuje na 6 px rodiče). Neaktivní kroky jsou bílé s rámečkem `secondary-200` a šedým číslem na `secondary-100`; hotové kroky jsou odkazy (hover `primary-50`). Popisek „KROK 1“ je jediné místo s verzálkami. Pod 820 px: 52 px, název jen u aktivního kroku, ostatní jen číslo.
