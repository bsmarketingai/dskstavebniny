# CartBar

Plovoucí lišta na spodku košíku (všechny 3 kroky) — tmavý pás `primary-800` se stínem `shadow-bar`, poslední prvek stránky (v košíku není FAQ, newsletter ani patička). Vlevo „Zpět…“ (`dsk-btn--on-dark-outline`, 64 px), vpravo u tlačítka souhrn: Poštovné a balné + Konečná cena s DPH (32/36 bíle), a konverzní „Pokračovat“ s dvouřádkovým popiskem (64 px). Pod 820 px: nahoře řádek poštovné vlevo / konečná cena vpravo, pod ním Zpět (jen ikona) a Pokračovat přes zbytek šířky, 52 px.
