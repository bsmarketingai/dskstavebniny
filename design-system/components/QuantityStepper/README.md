# QuantityStepper

Číselník `dsk-qty` (44 px, rámeček `secondary-200`, `radius-sm`; v detailu `--lg` 52 px). Hodnota vždy i s jednotkou („1 ks“, „10 ks“). Skupina `dsk-addtocart` = číselník + čtvercové konverzní tlačítko s ikonou košíku (karta), v detailu číselník + „Koupit“. Ikona mínus je obdélník, ne čára s nulovou výškou.
