# CategoryTile

`dsk-ctile` — dlaždice podkategorie (výpis kategorie, vyhledávání): bílá, rámeček `secondary-200`, `radius-md`, obrázek 44 px s `radius-sm`, název 700 14/18 `primary-800`; hover `primary-50` + zvednutí o 2 px se stínem. Mřížka 6 sloupců, na mobilu 2.

`dsk-hcard` — karta hlavní kategorie (homepage Sortiment, stránka Sortiment): tmavá `primary-900` s fotkou, `radius-lg`, název bíle (homepage 22/26, velká karta na stránce Sortiment 44/48), popis `primary-200`. Velká karta má čipy podkategorií (bílá 18 %) a tlačítko `--on-dark` „Zobrazit kategorii“, malá karta šipku `primary-800` vpravo dole. Rychlé výběry (Akce, Cenově výhodné, Unikátní, Top) nad kartami jsou `dsk-pick`.
