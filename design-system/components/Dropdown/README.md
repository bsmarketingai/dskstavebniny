# Dropdown

Rozbalovací menu položek kategoriové lišty — **Služby** a **Články**. Otevírá se najetím myší nebo fokusem z klávesnice; panel bílý, `shadow-pop`, spodní rohy `radius-lg`. Položky 600 15/20 `primary-800` s chevronem `primary-600`, `radius-md`, hover `primary-100`. Dole oddělený odkaz na celek („Všechny články“). Na mobilu stejný obsah akordeonem v hamburger menu.

Služby: Nová zelená úsporám, Lidské zdroje na stavbě, Vyhledávání zakázek, Investiční záměr, Rozvoz zboží včetně vykládky, Veřejné výstavky dlažeb, Přívěsný vozík k odvozu zboží, Nářadí na stavbě, Míchací centrum, Řezání materiálu.
