# Dropdown

Rozbalovací menu položky v modré liště (zatím Články). Otevírá se najetím myší nebo fokusem z klávesnice, položky mají stejný styl jako postranní strom kategorií: 15 px, `primary-800`, oddělovač `secondary-200`, hover `primary-50`. Na mobilu je stejný obsah akordeonem v hamburger menu. Kategorie článků: Tepelné izolace, Barvy, nátěry, omítkoviny, Okna a dveře, Fasády, Interiér, Dlažby, ploty a schody, Hrubá stavba, Stavební chemie, Pórobeton, Vyzkoušeli jsme pro vás.
