# Badge

Štítky produktů (`--sale` Výprodej, `--new` Novinka, `--discount` sleva v %, `--info` Věrnostní program / Cenově výhodný produkt), počítadlo notifikací `dsk-counter` (vždy oranžové, u košíku, porovnání i počtu filtrů) a stav prodejny `dsk-status`. Štítky se v kartě skládají pod sebe vlevo nahoře. Verzálky nepoužíváme.
