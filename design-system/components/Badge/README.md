# Badge

Štítky produktů v kartě vlevo nahoře pod sebou: `--sale` Výprodej (červená), `--new` Novinka (`primary-800`), `--discount` sleva v %, `--info` Cenově výhodný produkt. Štítek kampaně na tmavém banneru `--promo` (oranžový: „Akce do vyprodání zásob“, „Sezóna zateplování“) a průhledný `--glass` (kicker na barevném hero, např. NZU). Počítadlo `dsk-counter` je vždy oranžové, kulaté 20 px (košík, porovnání, počet filtrů). Stav prodejny `dsk-status` = zelená tečka + text (utility lišta, modal prodejen). Verzálky nepoužíváme.
