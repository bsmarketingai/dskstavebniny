# Dialog

Kostra vrstev: modal (Přihlášení, Vybrat prodejnu, Vložili jste do košíku), popover (mini košík) a šuplík (filtr). Bílá, `radius-lg`, `shadow-pop`, padding 20–32 px podle šířky. Hlavička: ikona ve čtverci 44 px + nadpis 26/32 `primary-700` + šedý podnadpis, vpravo zavírací křížek 44 px. Modal: `role="dialog"`, `aria-modal`, ztmavené pozadí `dsk-scrim` (klik zavře), Esc zavře, fokus jde do vrstvy. Na mobilu se mini košík otevírá jako modal přes celou šíři. Karty prodejen v modalu jsou bílé s rámečkem, vybraná `primary-50`; u každé telefon i e-mail. BSSHOP: `bs-dialog bs-tab-boundary` (modal), `popup` (popover).
