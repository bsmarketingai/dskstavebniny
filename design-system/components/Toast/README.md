# Toast

Krátké potvrzení akce vpravo dole (Přidáno do porovnání, Uloženo). Bílá karta 360 px, `radius-lg`, `shadow-toast`, zelený čtverec s checkem, nadpis `success` 16/22, popis max. 2 řádky, volitelný odkaz („Zobrazit porovnání“) a zavírací křížek. Zmizí sám po ~4 s, s `prefers-reduced-motion` bez animace. `role="status"`.
