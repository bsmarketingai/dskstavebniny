# FormControls

Pole `dsk-field` (44 px, `--lg` 48 px v hlavičce), vyhledávání `dsk-search` (pole + tlačítko Hledat jako jeden celek; na XXS–XS jen ikona lupy), výběr `dsk-select` (řazení, varianty), zaškrtávátko `dsk-check` s počtem v `<small>`, čip aktivního filtru `dsk-chip` (32 px, odebírá se klikem). Každé pole má `<label>`; skryté popisky přes vizuálně skrytý text, ne placeholder.
