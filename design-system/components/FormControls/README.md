# FormControls

Formuláře (košík krok 2, poptávka, přihlášení): **popisek vždy nad polem** (`dsk-label`, 600 15/20), pole `dsk-input` 48 px, rámeček `secondary-400`, `radius-sm` (4 px). Fokus: rámeček `primary-600` + prstenec 3 px `primary-100` — jeden prstenec, ne dvojitý. Povinné pole má červenou hvězdičku, nepovinné šedé „(nepovinné)“. Výběr `dsk-select` má stejnou výšku a vlastní chevron; řazení ve výpisu `dsk-select--sort` 44 px. Zaškrtávátko 20 px, `accent-color` `primary-800`.

Vyhledávání v hlavičce `dsk-search`: bílé pole + tmavé Hledat jako jeden celek (radius jen vnějších rohů), na mobilu jen lupa. Čip aktivního filtru `dsk-chip` (32 px, `primary-100`, odebírá se klikem), vedle „Zrušit vše“ červeně. Rychlé výběry nad výpisem `dsk-pick` (Akce, Cenově výhodné…).
